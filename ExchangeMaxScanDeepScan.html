How the Script Works

Purpose

The script scans a Microsoft Exchange server’s public endpoints for version number leaks.
It detects build numbers in:

  • HTTP headers
  • HTML body text
  • Linked resources (CSS, JS, images, fonts)
  • url(...) references inside CSS

This is important because Exchange build numbers can reveal exact patch levels (CU/SU), which attackers can use to target known vulnerabilities.

Main Steps

1.   Setup

    • Accepts:
      • -ExchangeServerFQDN (required) — the hostname of the Exchange server.
      • -Credential (optional) — for endpoints requiring authentication.
      • -EmailAddress (optional) — for autodiscover POST testing.
    • Ignores invalid SSL certificates.
    • Forces TLS 1.2 for compatibility.
    • Creates a .\ExchangeScanLogs folder to store all fetched content.

2.   Target Endpoints

    • Scans:

Copy code

/owa/

/ecp/

/mapi/

/rpc/

/autodiscover/autodiscover.xml

    • Tries both HTTPS and HTTP for each.

3.   Fetching and Saving

    • Uses Invoke-WebRequest to fetch each endpoint.
    • Saves the raw HTML/CSS/JS to disk for later inspection.

4.   Version Detection

    • Uses a regex:

Copy code

15\.\d+\.\d+(?:\.\d+)?

This matches:

      • 15.1.2507 (major.minor.build)
      • 15.1.2507.12 (major.minor.build.revision)
    • Checks:
      • HTTP headers
      • HTML body
      • Link URLs before fetching (so even failed fetches still yield versions)
      • Content of fetched linked resources
      • CSS url(...) references

5.   Recursive Resource Scanning

    • Parses HTML for <a>, <script>, <link> tags.
    • Extracts URLs from CSS url(...) patterns.
    • Normalizes relative URLs to absolute.
    • Fetches each linked resource and scans it.

6.   Output

    • Displays a table of unique build numbers found, with:
      • Endpoint
      • Source (Header, Body, Link Reference, Resource Content, CSS URL Reference)
      • Build number
    • Saves all raw responses in .\ExchangeScanLogs.
    • Suggests a Select-String command to search logs manually.

Usage Examples

1.     Basic Scan (No Authentication)

 

.\ExchangeMaxScan-DeepScan.ps1 -ExchangeServerFQDN exchange.example.com

 

 

2. Scan with Credentials

$cred = Get-Credential

.\ExchangeMaxScan-DeepScan.ps1 -ExchangeServerFQDN exchange.example.com -Credential $cred

3. Scan with Autodiscover POST

$cred = Get-Credential

.\ExchangeMaxScan-DeepScan.ps1 -ExchangeServerFQDN exchange.example.com -Credential $cred -EmailAddress user@example.com

4. Search Saved Logs for Versions

Select-String -Path .\ExchangeScanLogs\* -Pattern '15\.\d+\.\d+(?:\.\d+)?'
