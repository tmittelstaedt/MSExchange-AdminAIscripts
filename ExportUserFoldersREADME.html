ExportUserFolders.ps1 – Script Documentation

Purpose

This PowerShell script is designed for use in the Exchange Management Shell to:

  • Identify all user-created and archive folders in a mailbox.
  • Exclude known system folders and other unwanted folders.
  • Generate a New-MailboxExportRequest command to export those folders to a PST file.
  • Save that command to a specified output file.
  • Create a second file containing a command to remove only completed export jobs for that mailbox from the queue.

Parameters

ParameterRequiredDescription
-MailboxYesThe mailbox identity (alias, SMTP address, or display name).
-OutputFileYesPath to the file where the export command will be saved.
-ExportPathNoUNC path for the PST file. If not supplied, defaults to:
\\exchange.example.com\pst<MailboxName>.pst

Folder Filtering Logic

The script retrieves mailbox folders using:

Get-MailboxFolderStatistics -Identity <Mailbox>

It includes:

  • Folders where FolderType is User Created
  • Folders where FolderType is Archive

It excludes the following folders:

Outbox
Outbox/VoiceOutbox
Sync Issues
Sync Issues/Conflicts
Sync Issues/Local Failures
Sync Issues/Server Failures
Conversation History
Junk Email
RSS Feeds
News Feed
Quick Step Settings

Folder Name Cleanup

  • Removes the leading slash (/) from folder paths.
  • Wraps all folder names in double quotes to ensure spaces and special characters are handled correctly.

Example:

/Projects
/Personal Stuff

becomes:

"Projects","Personal Stuff"

Export Command Creation

The script builds a single-line export command in the format:

New-MailboxExportRequest -Mailbox "<MailboxName>" -IncludeFolders "Folder1","Folder2" -FilePath "\\exchange.example.com\pst<MailboxName>.pst"

This command is saved to the file specified by -OutputFile.

Remove Command Creation

The script also creates a second file with the same name as the first, but with "Remove" inserted before the extension.

Example:

C:\Temp\ExportCommand.txt
C:\Temp\ExportCommandRemove.txt

The remove file contains a command that only removes completed export jobs for that mailbox:

Get-MailboxExportRequest -Mailbox "<MailboxName>" | Where-Object {$_.Status -eq "Completed"} | Remove-MailboxExportRequest

Example Usage

Run with default PST path:

.\ExportUserFolders.ps1 -Mailbox "TedMittelstaedt" -OutputFile "C:\Temp\ExportCommand.txt"

PST will be saved to:

\\exchange.example.com\pst\TedMittelstaedt.pst

Creates:

C:\Temp\ExportCommand.txt
C:\Temp\ExportCommandRemove.txt

Run with custom PST path:

.\ExportUserFolders.ps1 -Mailbox "TedMittelstaedt" -OutputFile "C:\Temp\ExportCommand.txt" -ExportPath "\\server\pstshare\TedMittelstaedt.pst"

PST will be saved to:

\\server\pstshare\TedMittelstaedt.pst

Example Output Files

ExportCommand.txt

New-MailboxExportRequest -Mailbox "TedMittelstaedt" -IncludeFolders "Projects","Personal Stuff","Archive/Old Projects" -FilePath "\\exchange.example.com\pst\TedMittelstaedt.pst"

ExportCommandRemove.txt

Get-MailboxExportRequest -Mailbox "TedMittelstaedt" | Where-Object {$_.Status -eq "Completed"} | Remove-MailboxExportRequest

Key Benefits

  • Safe: Only removes completed export jobs.
  • Accurate: Filters out unwanted system folders.
  • Flexible: Supports both user-created and archive folders.
  • Consistent: Always quotes folder names to avoid parsing errors.
