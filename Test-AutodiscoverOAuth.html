Test-AutodiscoverOAuth.ps1 – Usage & Setup Guide

Purpose

This PowerShell script tests OAuth-based Autodiscover for Exchange Online mailboxes, simulating how a mobile client would authenticate using Modern Authentication.

  • Prompts for an email address.
  • Automatically determines the tenant ID from the domain.
  • Uses the OAuth 2.0 device code flow to authenticate.
  • Sends an Autodiscover request to Exchange Online using the acquired token.
  • Displays the raw XML response from Autodiscover.
  • Warns if no mailbox settings are returned (expected if the mailbox is on-premises and Hybrid Modern Authentication is not yet enabled).

When to Use

  • Before Hybrid Modern Authentication – Confirm that cloud Autodiscover returns no settings for on-prem mailboxes (baseline test).
  • After Hybrid Modern Authentication – Verify that OAuth Autodiscover works for both cloud and on-prem mailboxes.

Script Usage

  1. Save the script as Test-AutodiscoverOAuth.ps1.
  2. Open PowerShell.
  3. Run:
    .\Test-AutodiscoverOAuth.ps1 -ClientId "<Your-App-Client-ID>"
  4. Enter the full email address when prompted.
  5. Follow the on-screen instructions to:
    • Open the provided URL in a browser.
    • Enter the device code.
    • Sign in with the test account (MFA supported).
  6. The script will:
    • Query Exchange Online Autodiscover.
    • Display the raw XML.
    • Show a warning if no mailbox settings are returned.

Expected Output Examples

Pre-Hybrid (On-Prem Mailbox)

Raw Autodiscover XML Response:
500The email address can't be found.
WARNING: No mailbox settings returned. This is expected if the mailbox is on-premises and Hybrid Modern Authentication is not yet enabled.

Post-Hybrid (Mailbox Found)

Raw Autodiscover XML Response:

<Autodiscover>
  <Response>
    <Account>
      <Protocol>...</Protocol>
    </Account>
  </Response>
</Autodiscover>

Azure AD App Registration Setup

Step 1 – Create the App Registration

  1. Sign in to the Azure Portal.
  2. Go to Azure Active Directory → App registrations → New registration.
  3. Name the app (e.g., Autodiscover OAuth Test).
  4. Supported account types: Accounts in this organizational directory only.
  5. Redirect URI: Leave blank for now.
  6. Click Register.

Step 2 – Enable Public Client Flows

  1. In the app registration, go to Authentication.
  2. Under Advanced settings, set Allow public client flows to Yes.
  3. Click Save.

Step 3 – Add API Permissions

Exchange Online (EWS)

  1. Go to API permissions → Add a permission.
  2. Select APIs my organization uses.
  3. Search for Office 365 Exchange Online.
  4. Select Delegated permissions.
  5. Expand EWS and check: 
    EWS.AccessAsUser.All
  6. Click Add permissions.

Azure Active Directory Graph

  1. Click Add a permission again.
  2. Select APIs my organization uses.
  3. Search for Azure Active Directory Graph.
  4. Select Delegated permissions.
  5. Expand Directory and check: 
    Directory.Read.All
  6. Expand User and check: 
    User.Read
  7. Click Add permissions.

Step 4 – Grant Admin Consent

  1. In API permissions, click Grant admin consent for your organization.
  2. Confirm the action when prompted.

Step 5 – Get the Client ID

  1. In the app registration, go to Overview.
  2. Copy the Application (client) ID — this is the value you pass to the script’s -ClientId parameter.

Security Notes

  • The script uses device code flow — no secrets or certificates are stored.
  • The access token is valid for a short time and is only used for the Autodiscover test.
  • Requires Modern Authentication to be enabled in Exchange Online (and Hybrid Modern Auth for on-premises mailboxes).

Post-Hybrid Testing

After enabling Hybrid Modern Authentication:

  • The script will return full Autodiscover settings for on-prem mailboxes.
  • You can use the same script without modification — it will work for both cloud and on-prem mailboxes.

Autodiscover OAuth Flow Diagram

Below is a simplified flow of how the script works: 

User → Script Prompt → Tenant ID Discovery → OAuth Device Code Request
→ User Sign-In (MFA Supported) → Access Token Received
→ Autodiscover Request to Exchange Online → Raw XML Response
